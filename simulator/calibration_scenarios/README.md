# calibration_scenarios

- What lives here: clean scenarios used only to fit the thermal twin (Phase 3). They are not part of the golden set and are never used to score detectors.
- Filled in by: Phase 3. Run `python -m simulator generate-calibration` to write the recordings into `data/calibration/` (seeds 9001 to 9010).
- Finding things: one YAML per scenario; every id starts with `calibration_`.
