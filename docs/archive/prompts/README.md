# archive/prompts

- What lives here: the prompt of every build phase (phase-00 to phase-06, then F1 to F5), kept as a record of what each phase was asked to do. You do not need them to run or use the project.
- Index: `phase-00` skeleton, `01` simulator, `02a` to `02d` live simulator, potency and constants, `03`, `03b`, `03c` twin and detectors, `04` signed records, `05` planner, `06` backend, `f1` art direction, `f2` front-end foundation, `f3` the story, `f4` control room, `f5` product pages.
- The phase reports in `docs/02-phase-reports/` say what each phase actually built.
