# dashboard

- What lives here: the cinematic Story and Control Room front end (Vite + React + TypeScript + three.js). Phase F2 built the foundation (app shell, scroll rig, 3D globe, quality governor, mode adapter, TypeScript potency mirror). Phase F3 built the Story (`src/story/`). Phase F4 built the first Control Room; Phase F5 replaced it with plain-language pages (`src/pages/`, words in `src/copy/`), a Simple/Technical switch and light and dark themes. The replay clock, store and approval rules are still in `src/controlroom/`.
- Run it: `npm run dev` (serves http://127.0.0.1:5173). `npm run build` and `npm test` check the code. Open `/?tier=high`, `/?mode=replay#/control-room` and so on.
- Pages: Home, Shipments, Shipment (one journey), Decisions, Proof, About this data, Story. Keys: `?` Help, Esc closes a dialog, Space and R on a shipment, 1 to 5 on the Shipments page, G Story, H Home, M reduced motion, F full screen, Q quality and D performance (Technical). `?rec=1` is recording mode: V starts and stops a scripted run through the pages (the cursor, hints and the performance overlay are hidden, quality is locked).
- Production build: `npm run build`, then `npx vite preview --host 127.0.0.1 --port 4173`.
- URL options: `?mode=story|replay|live` (data source, default story), `?tier=high|medium|low|fallback2d` (forces a quality tier). Keys: `?` shows the list; `Q` quality, `D` performance numbers, `M` reduced motion, `G` Story, `C` Control Room, Space and arrows to move.
- Source: `src/app` (navigation, help, tour, routes), `src/pages`, `src/copy` (the glossary and plain sentences), `src/scroll` (scroll rig and chapter table), `src/globe` (the globe), `src/quality` (governor), `src/data` (adapter and validation), `src/potency` (TypeScript potency mirror, tested against `shared/test-vectors/`), `src/theme` (tokens, fonts).
- Data: `public/replay/` is written by `python scripts/export_replay.py`; `public/story/` and `src/data/bundled/chapter1.json` by `python scripts/export_story.py`; `public/globe/` by `python scripts/make_land_mask.py` (README there names the source and licence). Fonts in `public/fonts/` are SIL OFL 1.1.
- Live mode reads the backend (`python -m backend serve`) through the dev proxy `/api`, read-only.
- OneDrive note: `node_modules` is a junction to `%LOCALAPPDATA%\potencyguard\dashboard-node_modules\node_modules`, so packages are not synced.
- Warning: a plain `npm install` or `npm ci` inside this folder REPLACES the junction with a real folder inside OneDrive. To add or change a package, follow docs/03-decisions/decision-0011-frontend-foundation.md section 1: install in `%LOCALAPPDATA%\potencyguard\dashboard-node_modules`, copy `package.json` and `package-lock.json` back, then check the junction.
