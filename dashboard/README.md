# dashboard

- What lives here: the PotencyGuard front end (Vite + React + TypeScript + three.js): the product pages (Home, Shipments, Shipment, Decisions, Proof, About this data) and the scroll Story. It reads recorded sample data; nothing is sent anywhere.
- Needs Node.js 22.12 or newer. Install the packages with `npm ci` (not `npm install`; it can change `package-lock.json`). `scripts\setup.ps1` does this for you.
- Run it: `npm run dev` (http://127.0.0.1:5173), or `scripts\run-demo.ps1` for the production build (http://127.0.0.1:4173). `npm run build` and `npm test` check the code.
- URL options: `?mode=replay|live` (default replay; live reads the backend status read-only through the dev proxy `/api` and falls back to the recordings), `?tier=high|medium|low|fallback2d` (forces a 3D quality tier), `?rec=1` (recording mode: V starts and stops a scripted run through the pages; cursor, hints and the performance overlay are hidden).
- Keys: `?` Help, Esc closes a dialog, Space and R on a shipment, 1 to 5 on the Shipments page, G Story, H Home, M reduced motion, F full screen, Q picture quality and D performance numbers.
- Source: `src/app` (navigation, help, tour, routes), `src/pages` (the pages), `src/copy` (the glossary and plain sentences), `src/controlroom` (replay clock, store, approval rules, chart), `src/story` and `src/scroll` (the Story), `src/globe` (the 3D globe), `src/quality` (quality governor), `src/data` (adapter and validation), `src/potency` (TypeScript potency mirror, tested against `shared/test-vectors/`), `src/theme` (tokens, light and dark themes, fonts).
- Data in `public/`: `replay/` is written by `python scripts/export_replay.py`; `story/` and `src/data/bundled/chapter1.json` by `python scripts/export_story.py`; `globe/` by `python scripts/make_land_mask.py` (its README names the source and licence). Fonts in `fonts/` are SIL OFL 1.1.
